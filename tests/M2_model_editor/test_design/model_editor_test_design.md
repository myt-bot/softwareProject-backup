# M2 前端模型搭建编辑器测试说明

## 1. 测试目标

本测试用于验证前端模型搭建编辑器当前版本的核心功能是否真实存在于项目代码中，并在后续修改时及时发现功能回退。

测试重点包括：

1. 单击、拖拽和键盘操作等多种节点添加方式。
2. 节点复制、粘贴、删除以及连线删除。
3. 撤销、重做、智能布局和适应视图。
4. 短模型竖向排列、长模型折列以及分支展开。
5. 模板加载后统一执行智能布局。
6. 结构检查问题归并、修改建议和错误定位。
7. 参数确认式校验和非法输入拦截。
8. 多输入连线独立落点、箭头方向适配和角度限制。
9. ModelGraph 数据导出。

## 3. 测试方法

本模块采用两类自动化测试：

### 3.1 真实源码契约测试

测试程序直接读取当前项目中的 TypeScript 和 Vue 文件，检查功能入口、事件绑定、状态处理和关键算法是否仍然存在。例如：

- `Ctrl+C` 是否调用 `copySelectedNode`。
- `Delete/Backspace` 是否调用 `deleteSelectedGraphItem`。
- 模板加载是否调用 `layoutGraphNodes`。
- 结构检查是否使用 `Set` 去重并合并连接类错误。
- 箭头是否使用 SVG `orient="auto"`。

这种方式不会像旧测试一样，在测试文件中重新实现一套与真实页面无关的简化编辑器逻辑。

### 3.2 可独立计算的边界测试

对于可以脱离浏览器计算的规则，测试文件会直接验证数学边界。例如顶部多输入箭头的水平偏转比例为 `0.625`，即最大偏离竖直方向约 32°。

## 5. 运行方法

在项目根目录执行：

```bash
node tests/M2_model_editor/test_code/test_model_editor.js
```

执行完整前端构建检查：

```bash
cd frontend
npm run build
```

## 6. 浏览器手动测试

以下视觉和拖拽行为仍需在浏览器中补充确认：

1. 单击组件后节点是否出现在合适位置。
2. 拖拽节点后连线是否实时跟随。
3. ResNet Tiny 多输入连线是否容易区分。
4. 箭头是否顺着线的方向且不会贴住节点边框。
5. 标签较多时右侧工具按钮是否始终可见。
6. 点击结构问题后节点是否进入可视区域，参数面板是否定位到对应字段。
7. 智能布局后用户是否仍能手动拖动调整。

## 7. 通过标准

满足以下条件时，M2 模型编辑器测试通过：

1. `test_model_editor.js` 全部 27 个用例通过。
2. `npm run build` 无 TypeScript 或 Vue 编译错误。
3. 浏览器手动测试中不存在节点遮挡、工具不可见、连线方向错误或问题无法定位等阻断性缺陷。
