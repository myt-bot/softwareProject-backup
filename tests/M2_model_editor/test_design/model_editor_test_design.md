# M2 前端模型搭建编辑器模块测试说明

## 1. 测试目标

本测试用于验证前端模型搭建编辑器模块的基本功能是否正确，包括模型层节点添加、节点删除、节点连接、参数修改、ModelGraph 导出以及异常输入处理。

测试目标是保证用户能够通过前端界面构建模型结构，并将当前画布内容转换为后端可接收的统一 ModelGraph 数据结构，为后续结构校验、代码导出和训练任务创建提供正确的数据基础。

## 2. 被测模块和负责代码路径

被测模块：前端模型搭建编辑器模块。

负责代码路径：

- `frontend/src/app.js`
- `frontend/src/styles.css`
- `frontend/src/api/client.js`

测试代码路径：

- `tests/M2_model_editor/test_code/test_model_editor.js`

测试说明路径：

- `tests/M2_model_editor/test_design/model_editor_test_design.md`

## 3. 测试范围

本模块测试范围包括：

- 添加模型层节点
- 删除模型层节点
- 建立节点连接
- 删除节点连接
- 修改节点参数
- 导出 ModelGraph
- 非法连接处理
- 空画布处理
- 参数为空或参数非法处理
- 前端向后端 Validate 接口提交模型结构

## 4. 不测试的内容

以下内容不属于本模块主要测试范围：

- 用户注册、登录、退出和项目保存读取
- 后端模型结构合法性完整校验
- Conv2D、Pooling、Flatten、Linear 的维度推导算法
- 训练任务创建、训练过程和训练指标返回
- PyTorch 代码生成的具体内容正确性
- 模板接口加载逻辑

上述内容由其他模块负责。本模块只验证前端能够正确构造、修改和提交 ModelGraph，并能够展示后端返回结果。

## 6. 预期结果

完成测试后，前端模型编辑器应满足以下结果：

1. 用户可以正常添加、删除模型层节点。
2. 用户可以建立和删除节点之间的连接。
3. 系统能够阻止自连接和重复连接。
4. 用户修改节点参数后，节点 `params` 数据同步更新。
5. 系统可以稳定导出统一 ModelGraph 数据结构。
6. 空画布、参数为空、后端未启动等异常情况不会导致页面崩溃。
7. Validate、Export、Train 等按钮在接口异常时能够给出提示。
8. Flatten、Output 等无参数节点能够正常显示说明，不影响其他节点编辑。

## 7. 异常情况考虑

本模块主要考虑以下异常情况：

1. 空画布导出时，应返回空 `layers` 和空 `connections`。
2. 节点删除后，应同步删除与该节点相关的连接，避免导出脏数据。
3. 用户尝试自连接时，系统应拒绝。
4. 用户尝试重复连接时，系统应拒绝。
5. 用户输入空参数或非法参数时，系统应提示错误或保持未校验状态。
6. 后端服务未启动或接口未实现时，前端应显示提示，不能出现页面崩溃。
7. 模型结构深层合法性检查和维度推导由后端 validator 模块完成，前端只负责构造和提交 ModelGraph。
