# M2 前端模型搭建编辑器模块测试说明

## 1. 测试目标

本测试说明用于验证 M2 前端模型搭建编辑器模块的功能正确性、数据结构稳定性和异常情况处理能力。

前端模型搭建编辑器模块主要支持用户通过可视化方式搭建深度学习模型结构，包括添加模型层节点、删除模型层节点、建立节点连接、删除节点连接、修改节点参数，并将当前画布内容导出为后端可接收的 ModelGraph 数据结构。

本模块测试目标如下：

1. 验证用户能够正常添加 Input、Conv2D、Pooling、Flatten、Linear、Dropout、Output 等模型层节点。
2. 验证用户能够正常删除节点，并同步清理与该节点相关的连接。
3. 验证用户能够建立节点连接，并阻止自连接、重复连接等非法连接。
4. 验证用户能够在右侧参数面板修改 Input、Conv2D、Pooling、Linear、Dropout 等节点参数。
5. 验证右侧参数输入框在回车或失焦确认后进行校验，非法数值不会更新到画布节点中。
6. 验证系统能够正确导出统一的 ModelGraph 数据结构。
7. 验证空画布、参数为空、非法参数、后端未启动等异常情况不会导致页面崩溃。
8. 验证前端能够将 ModelGraph 提交给后端 Validate、Export、Train 等接口，并对返回结果或异常情况进行提示。

以下内容不属于 M2 前端模型搭建编辑器模块的主要测试范围：

1. 用户注册、登录、退出功能。
2. 项目新建、保存、读取和删除功能。
3. 后端完整模型结构合法性校验。
4. 后端维度推导算法。
5. Conv2D、Pooling、Flatten、Linear 等层的具体维度计算过程。
6. 训练任务的实际执行过程。
7. loss、accuracy 等训练指标的真实计算过程。
8. PyTorch 代码生成内容的完整正确性。
9. 模型模板接口的具体实现。
10. 数据库存储和用户权限控制。

说明：

M2 模块主要负责前端画布编辑和 ModelGraph 构造。缺少 Input、缺少 Output、孤立节点、连接断裂、循环连接、Conv2D 维度推导、Pooling 维度推导、Flatten 维度推导、Linear 维度不匹配等深层结构检查主要由后端结构检查与维度推导模块负责。M2 模块只验证前端是否能够正确构造、修改和提交 ModelGraph，并能够展示后端返回结果。前端参数校验主要负责拦截明显非法的输入，例如空值、负数、非数字、Dropout 比例超出范围等。

## 6. 预期结果

完成测试后，M2 前端模型搭建编辑器模块应满足以下结果：

1. 用户可以正常添加 Input、Conv2D、Pooling、Flatten、Linear、Dropout、Output 等模型层节点。
2. 用户可以正常删除模型层节点，并且删除节点时与该节点相关的连接会同步删除。
3. 用户可以正常建立节点之间的连接。
4. 用户可以正常删除节点之间的连接。
5. 系统能够阻止自连接、同方向重复连接、反方向重复连接和不存在节点连接等异常情况。
6. 用户可以通过右侧参数面板修改 Input、Conv2D、Pooling、Linear、Dropout 等节点参数。
7. 参数修改后，节点内部 `params` 数据能够同步更新。
8. 参数修改后，画布节点中的 note 或 Shape Hint 能够同步更新。
9. 右侧参数输入框采用确认式校验，用户按回车或输入框失焦后才提交修改。
10. 当用户输入空值、非数字、负数或超出范围的参数时，系统能够显示错误提示，并保持画布节点原参数不变。
11. Flatten、Output、ReLU 等无参数节点能够正常显示说明，不影响其他节点编辑。
12. 系统能够正确导出统一的 ModelGraph 数据结构。
13. 导出的 ModelGraph 中，`layers` 为数组，`connections` 为数组。
14. 每个 layer 对象包含 `id`、`type`、`name`、`params` 字段。
15. 每个 connection 对象包含 `source`、`target` 字段。
16. 空画布导出时系统不崩溃。
17. 参数为空或非法输入时，系统能够提示错误并阻止非法参数写入。
18. 后端未启动或接口异常时，前端能够显示提示信息，不会导致页面崩溃。
19. Validate、Export、Train 等按钮能够按照当前状态正常响应。

## 7. 异常情况考虑

本模块主要考虑以下异常情况：

1. 空画布导出：当画布中没有节点和连接时，导出的 ModelGraph 应包含空的 `layers` 和 `connections` 数组，页面不应崩溃。
2. 自连接：当用户尝试将一个节点连接到自身时，系统应拒绝该操作，并给出提示。
3. 重复连接：当两个节点之间已经存在连接时，系统应拒绝再次添加相同连接。
4. 反方向重复连接：当两个节点之间已经存在连接时，系统应避免用户建立反向重复连接，防止形成简单环或重复边。
5. 节点不存在：当连接的源节点或目标节点不存在时，系统不应添加该连接。
6. 删除节点：删除节点时，应同步删除所有以该节点为 source 或 target 的连接，避免导出脏数据。
7. 删除连接：删除连接时，只删除对应连接，不应影响其他节点和连接。
8. 参数为空：当用户清空参数输入框后按回车或失焦确认时，系统应提示参数不能为空，不应将空值直接写入节点参数。
9. 参数非数字：当用户在数字参数输入框中输入非数字内容并确认时，系统应提示格式错误，并保持节点原参数不变。
10. 参数为负数：当用户将输出通道数、卷积核大小、步长、全连接输出特征数等参数设置为负数时，系统应拒绝更新并显示错误提示。
11. 参数超出范围：当 Dropout 比例小于 0 或大于 1 时，系统应拒绝更新并显示错误提示。
12. Input Shape 非法：当 Input Shape 包含字母、空项、0 或负数时，系统应拒绝更新并提示格式错误。
13. 后端未启动：当前端调用 Validate、Export 或 Train 接口时，如果后端未启动，应显示连接失败提示。
14. 后端返回错误：如果后端返回校验失败、接口异常或训练失败信息，前端应展示错误信息，而不是页面崩溃。
15. 页面交互异常：对于拖拽、右键菜单、连线点击区域、Toast 提示和按钮状态变化等 UI 行为，需要结合浏览器进行手动测试。

补充说明：

自动化测试主要验证模型编辑器核心数据结构操作逻辑，包括节点增删、连接合法性、参数修改、非法参数拒绝和 ModelGraph 导出。对于拖拽、右键菜单、连线点击区域、Toast 提示、按钮交互、浏览器显示效果等页面行为，需要结合浏览器进行手动测试。

本模块不重复实现后端 validator 的完整结构检查与维度推导逻辑。模型结构深层合法性检查、维度推导和训练前完整校验由后端对应模块完成，前端主要负责构造、修改、导出和提交 ModelGraph。
